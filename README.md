# underdog-web-challenge
언더독 웹 개발 챌린지 학습 기록

이름: 노현정

지원 동기: 지난 1학기 때 여러 동기들과 팀을 맺고, 대회를 나가며 대외활동도 경험하고 싶었습니다. 하지만 생각보다 마음이 맞는 동기를 찾기 힘들었고, 아쉬운 결과를 도출하였습니다. 또한 이전에 활동을 하며 느꼈던 저의 부족함, 개발을 임할 때 AI를 딸깍 하는 것이 아니라 그 코드를 이해하고 수정하는 과정에 대해 혼자서는 발전하기 쉽지 않다는 것을 알게 되었습니다. 그러다 주변 동기들이 언더독에서 배우고 수행하는 과정을 보며 저 또한 이 좋은 환경 속에 속하고 싶다는 생각이 들었습니다. 

배우고 싶은 것: 코드를 보고 분석하는 방법, 알고리즘 설계 방법, 대외활동을 통한 여러 경험


프로젝트 소개 : html을 중심으로 만든 저를 소개하는 웹사이트 입니다. css를 통해 디자인적인 부분을 수정하였고, github를 통해 웹사이트를 배포하였습니다.

사용한 기술: HTML, CSS

주요 기능 : 
1. 웹사이트의 Github 방문하기 버튼을 누르면 바로 Gitub 사이트로 넘어가는 기능
2. 이미지 넣는 기능
3. css 속에서 여러 여백과 텍스트, 색을 조정하며 미감을 높이는 기능
   
페이지 구성 : Header - Main - Footer

실행 방법 : 코드를 붙여넣은 후 vscode에서 Ctrl + F5 누르기 또는 Velog 속 웹사이트 링크 누르기

배포 링크 : https://hyeonjeong77.github.io/underdog-web-challenge/

작업하며 배운 점 :
1. Html 언어
2. css와 연동하는 법
3. github commit 하는법
4. velog 사용
